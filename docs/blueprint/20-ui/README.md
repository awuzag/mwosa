이유와 이동 규칙은 `10-sitemap`에 두고 이 폴더에서 다시 정의하지 않는다.

- 예제: [.examples/UI_A_01_order_checkout_wireframe.md](.examples/UI_A_01_order_checkout_wireframe.md)
