# 웹 애플리케이션

웹 화면이 필요한 기능에 한해 route, 렌더링 경계, 상태 소유권, BFF, 배포와
관측성 결정을 기록한다. 현재 mwosa CLI 기능에는 필수 단계가 아니다.

- 웹 애플리케이션 템플릿: [.template/WEB_A_XX_web_application.md](.template/WEB_A_XX_web_application.md)
- BFF 모듈 템플릿: [.template/BFF_A_XX_bff_module.md](.template/BFF_A_XX_bff_module.md)

페이지 목적과 UI 근거, 도메인 규칙은 각각 앞 단계 문서를 링크하고 이
폴더에서 복제하지 않는다.
