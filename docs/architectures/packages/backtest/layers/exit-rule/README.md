# ExitRule

`ExitRule`은 보유 포지션을 줄이거나 청산할 조건을 판단한다. 청산 규칙은 손실 제한과 수익 유지 방식을 결정하므로 시스템 성격에 큰 영향을 준다.

초기 구현은 [거래 원칙](../../../trading-principles/README.md)에 따라 최근 저가 이탈, 이동평균 이탈, 손절선 이탈처럼 차트로 복기 가능한 조건을 우선한다.

다중 타임프레임 전략에서는 [타임프레임 설계](../../timeframes/README.md)에 따라 상위 타임프레임의 추세 이탈과 진입 타임프레임의 청산 신호를 함께 볼 수 있다.

## 책임

- 보유 포지션별 청산 조건을 판단한다.
- 손절, 익절, 추세 이탈, 시간 청산 같은 규칙을 표현한다.
- 부분 청산과 전량 청산 의도를 구분한다.
- 청산 사유를 기록 가능하게 만든다.

## 입력

- 현재 포트폴리오와 보유 포지션
- 시장 데이터
- 진입 가격, 보유 기간, 최고 평가 수익률 같은 포지션 메타데이터
- 전략별 청산 파라미터
- 상위, 진입 타임프레임 데이터

## 출력

- 청산 신호
- 매도 주문 의도
- 청산 사유
- 손절선, 추적 손절선, 채널 하단 같은 기준값

## 구현 후보

- 직접 구현: 청산 의도와 청산 사유 모델은 포트폴리오와 주문 실행 흐름에 맞춰 직접 구현해야 한다.
- [cinar/indicator](https://github.com/cinar/indicator): 이동평균, 채널, 변동성 지표를 이용한 청산 규칙 실험에 참고할 수 있다.
- [TA-Lib](https://ta-lib.org/): ATR, Bollinger Bands 같은 지표 계산 결과를 비교 검증하는 기준 후보.
- [Gonum](https://github.com/gonum/gonum): 추적 손절, 변동성 계산, 통계 기반 청산 조건을 직접 구현할 때 쓸 수 있는 수치 계산 후보.

## 조사할 자료

- 터틀 트레이딩의 저가 채널 이탈 청산 규칙
- 고정 손절, ATR 기반 손절, 추적 손절 방식
- 미국 ETF 장외 시간, 낮은 유동성, 급격한 스프레드 확대 상황에서 청산 실패 처리
- 부분 청산과 피라미딩 포지션 축소 방식

## 설계 쟁점

- 청산 규칙이 진입 규칙보다 우선 실행되어야 하는지 정해야 한다.
- 손절 주문은 장중 즉시 실행할지, 종가 또는 다음 시가 기준으로 처리할지 정해야 한다.
- 상위 타임프레임 청산 신호와 하위 타임프레임 손절 신호의 우선순위를 정해야 한다.
- 청산 실패가 발생했을 때 다음 이벤트에서 재시도할 규칙이 필요하다.
- 여러 청산 사유가 동시에 발생할 때 대표 사유와 상세 사유를 모두 남길지 정해야 한다.
